# SideForge Wiki

SideForge is a Windows x64 VST3 and Standalone sidechain processor (JUCE 8). It combines a sidechain compressor, a drawable
rhythmic gain curve, multiband and mid/side control, and spectral collision ducking. Every engine produces a `0..1` gain
signal, so the engines blend by multiplication, and only the band stage touches the audio.
