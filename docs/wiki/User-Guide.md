# User Guide

The README has the full guide: requirements, installing, routing the sidechain, using it, the Band Matrix, right-click and MIDI learn, latency and quality modes, factory presets and troubleshooting.

Short version:

1. Install the VST3 (or run the Standalone). Route the sidechain source to the plugin's sidechain input.
2. Choose a mode (Compress, Curve, Band Matrix or spectral collision) and adjust the controls. Right-click for reset, MIDI learn and automation.
3. Pick a quality setting. The latency it reports is the latency the host must compensate.
